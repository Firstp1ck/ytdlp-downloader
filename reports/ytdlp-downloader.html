ytdlp-downloader

A Firefox/Zen WebExtension plus a local Python native messaging host. Right-click a YouTube video, pick Download Video, and yt-dlp downloads it in the background using defaults from a settings page. Both halves are built, integrated, independently reviewed twice, and fixed. All automated checks pass. Loading the add-on in a real browser is the one acceptance step left to the user.

Residual risks and limitations

  • YouTube changes can break yt-dlp at any time. Update yt-dlp; the settings page shows its version.
  • Firefox release enforces signing, so a permanent install there needs AMO (unlisted) signing. Zen, Developer Edition, Nightly, and LibreWolf can use the unsigned .xpi.
  • Not covered: Flatpak/Snap browsers, Windows/macOS, cookies for login-gated videos, resuming a cancelled download.
  • The download list is in memory and gone after a browser restart. Two options tabs saving at the same moment can still race (low).
  • Real playlist downloads weren't run end to end. The argv and the playlist URL logic are unit-tested.

Next steps

  1. Run ./native-host/install.sh from the repository.
  2. In Zen: about:debugging#/runtime/this-firefox → Load Temporary Add-on… → extension/manifest.json.
  3. Open the add-on's settings and check that the Native host status panel shows yt-dlp and ffmpeg.
  4. Right-click a YouTube thumbnail → Download Video, and watch the toolbar popup.
  5. For a permanent install in Zen, set xpinstall.signatures.required=false and install the zipped .xpi (see DEVELOPMENT.md).
