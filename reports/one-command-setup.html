One-command setup (v1.3.0)

After installing the extension, a setup page opens and shows one command. It installs the helper (pinned to the release, checksum-verified), offers to install yt-dlp, ffmpeg and Deno, and the page turns green by itself. Two independent reviews found three medium issues in the first version: a cut-off download could run without flags, a broken yt-dlp showed "Ready", and no JavaScript runtime was set up. All three were fixed and re-verified. What remains unverified is live-browser behaviour and real package-manager runs.

Residual risks and next steps

  • Publish v1.3.0 first. The setup command's URL only works once the v1.3.0 release with its setup.sh and ytdlp_host.py assets exists.
  • Live browser: install the new .xpi in Zen and confirm the setup tab, Copy and the automatic Ready.
  • Upstream "latest": standalone yt-dlp and Deno are deliberately unpinned. Checksums protect integrity against the project's own list, not authenticity.
  • Distro coverage: package names were set per distro and tested with fakes only; Fedora's yt-dlp/ffmpeg-free and openSUSE's names are the least certain.
  • Existing users on helper 1.0.0 see "Update the helper" after the update (same command).
